⚙️ Under the Hood

Our Architecture

A deep dive into the machine learning architecture that powers CoffeeGuard AI.

📐

SVM Classifier

Our Support Vector Machine implements a balanced linear classifier that creates optimal decision boundaries for the 28,672 extracted features across multiple color spaces.

🌳

XGBoost Model

The Extreme Gradient Boosting component utilizes 200 sequentially planted decision trees with a max depth of 6 to capture complex non-linear patterns in leaf textures.

🤝

Soft Voting Ensemble

We combine both models using a soft voting classifier. By averaging the projected class probabilities of both SVM and XGBoost, we achieve superior generalization.

🖼️

Feature Engineering Pipeline

Before prediction, every user-uploaded image is securely processed. It is standardized to a 64x64 resolution and transformed into a 7-channel feature stack (Grayscale, BGR, and HSV). This creates a highly descriptive 28,672 feature vector that captures both texture and specific color markers of foliar diseases. The input array is then normalized using our pre-fitted StandardScaler.
